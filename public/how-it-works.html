How this portfolio is built & what happens behind the scenes

A visual tour of the site at arumuga-gomathi.github.io/my-portfolio — the stack, the files, the build pipeline, the browser runtime, and the auto-deploy flow.

1The stack

A static single-page site. No backend, no database, no server code.

UI

React 19 + TypeScript

Components render resume content from a single data file. TypeScript type-checks everything before bundling.

Build

Vite 6 + Rollup

Dev server with hot-reload; production bundler that tree-shakes and hashes output files.

Style

Tailwind CSS v4 + shadcn-style UI

Utility classes + Button/Badge/Card primitives built on cva + tailwind-merge. Class-based dark mode.

Motion & icons

Framer Motion + lucide-react

Scroll-reveal animations and icons. Largest chunk of the JS bundle — see §4.

3Dev vs build pipeline

Two npm scripts, two very different code paths.

npm run dev

Development server

Vite serves index.html + src/main.tsx as native ES modules — no bundling. Edits hot-swap in the browser in milliseconds.

npm run build

Production build → dist/

Stage 1: tsc -b type-checks; any error fails the build. Stage 2: Rollup bundles 2,091 modules into hashed files. base: './' keeps paths relative so the same output works on Pages, custom domains, or S3+CloudFront.

Real output of this site's build

dist/index.html                  1.70 kB │ gzip:  0.82 kB
dist/assets/index-*.css         29.95 kB │ gzip:  6.13 kB
dist/assets/index-*.js         421.29 kB │ gzip: 132.77 kB
✓ built in ~8s

Hashed filenames (e.g. index-BnJH4tds.js) change only when content changes, so browsers cache aggressively and always fetch fresh code after a deploy.

4Browser runtime

What happens between typing the URL and seeing the page.

1 · HTMLindex.html loads; inline script restores theme from localStorage before first paint — no dark-mode flash
→
2 · Bundlesingle hashed JS + CSS download; React hydrates into #root
→
3 · RevealIntersectionObserver (Framer Motion whileInView) animates each section in once on scroll
→
4 · Interactsticky nav blur on scroll, theme toggle persists, contact form composes a mailto: — no server involved

Where the 421 KB goes

React + ReactDOM and Framer Motion dominate the bundle; the site's own code is a small fraction. If load time ever matters, the levers are: lazy-load Framer Motion, drop it for CSS-only reveals, or code-split per section.

5Auto-deploy flow

Every push to main ships the site with zero manual steps.

git pushto main on GitHub
→
WorkflowUbuntu runner: npm ci → npm run build
→
Artifactdist/ uploaded via upload-pages-artifact
→
Livedeploy-pages publishes to the Pages URL

One-time setup that was needed

  • Pages Source → GitHub Actions enabled via API (build_type: workflow).
  • First run failed because Pages wasn't enabled yet — re-running the failed jobs went green.
  • Commits use the users.noreply.github.com email to satisfy the account's private-email push protection (GH007).
  • Portable gh CLI lives in %LOCALAPPDATA%\Programs\gh and is wired as the git credential helper.
